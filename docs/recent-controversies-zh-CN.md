## 1. PCL 联机服务重开及再次关闭（2025）

### 时间与记录

- **2025-10-24：** PCL 维护者发布“联机、再开”更新说明，宣布 PCL 联机功能重新开放。[PCL 维护者更新帖](https://www.bilibili.com/opus/1127340164029349892/)
- **2025-12-09：** 维护者发布再次暂时关闭说明，并称 PCL 联机在 2025-10-24 至 2025-11-16 期间开放。[PCL 维护者关闭说明](https://www.bilibili.com/opus/1135872352762986504)
- PCL 的公开 Wiki 记录了“简洁联机标记约定”及邀请代码格式，并注明协议使用 EasyTier 网络组网。[PCL Wiki：简洁联机标记约定](https://github.com/Meloong-Git/PCL/wiki/%E7%AE%80%E6%B4%81%E8%81%94%E6%9C%BA%E6%A0%87%E8%AE%B0%E7%BA%A6%E5%AE%9A)

### 维护者在关闭说明中的陈述

2025-12-09 的说明将暂时关闭与以下事项联系起来：

1. 维护者称多个节点连续一周以上遭到来源不明的 DDoS 攻击；其说明称，关闭前两天统计到的联机失败率约为 50%。
2. 维护者称当时的运行模式存在合规方面的问题，并表示在相关问题解决前，不开放共享节点搭建。
3. 维护者称近期存在“有组织地带节奏”的商家。该说法是维护者对相关舆论的描述，帖子没有列出对象或可独立核验的证据。
4. 维护者表示，联机功能暂时关闭；2025-10-24 至 2025-11-16 期间提供过赞助的用户可在 2025-11-23 前申请全额退款，退款后保留原有赞助额度和福利。

以上关于攻击、失败率、合规问题和舆论组织的内容均为维护者公告中的陈述，本文没有独立的网络测量、平台记录或法律文件可验证其成因或规模。公开的 Wiki 协议说明可佐证该服务涉及 EasyTier，但不能单独证明攻击或合规主张。

一篇 2025-11-28 的社区文章记述了围绕公共节点、志愿节点、流量与维护责任的讨论。[社区文章](https://blog.neclyon.dev/posts/my-thoughts-on-the-link-feature-being-shut-down/) 属于个人记录和评论，不是 PCL 或 EasyTier 的正式事故报告。

## 2. HMCL 海外下载源选项与地区识别讨论（2026-03）

HMCL 仓库 Issue #5864 提议在中国大陆以外禁用下载源设置，理由包括海外用户默认连接官方源的体验、镜像流量，以及对 Minecraft EULA 的担忧。[HMCL Issue #5864](https://github.com/HMCL-dev/HMCL/issues/5864)

2026-03-28，HMCL 维护者回复称，项目当时通过系统设置识别中国大陆，准确率不能达到 100%，因此应保留该选项以减少地区误判造成的影响。该 Issue 随后以 **not planned** 关闭。提议者也承认时区判断容易误判，并表示长远仍值得研究更准确的识别方式。

这条记录涉及的是**下载源选项是否应按地区隐藏**，不是后来的“关闭 Minecraft 本体下载”决定。Issue 中关于 EULA 的内容是参与者提出的考量；该讨论本身没有法律机构认定或 EULA 解释结论。

## 3. 2026-10-20 游戏本体下载与安装限制

### PCL

PCL 2.99.0.0 的公开发布讨论日期为 2026-10-20。维护者写明，PCL 不再提供 Minecraft 下载功能，并将此变更与“遵守相关法律法规”相联系；同一条说明称与网易、微软及 Mojang 无关。[PCL 2.99.0.0 发布讨论](https://github.com/Meloong-Git/PCL/discussions/9512)

PCL 公布的更新记录将该项目描述为移除游戏下载功能。所查公开说明没有列出具体法规条款、执法文书、举报材料或恢复日期。因此，本文能确认的是**维护者公开给出的理由和功能变更**，不能据此确认具体的外部原因或法律判断。

### HMCL

HMCL 维护者于 2026-10-20 合并 PR #7017，标题为“在中国大陆地区禁用游戏下载功能”。相关提交说明写有添加中国大陆地区下载提示并遵守相关法规。[HMCL PR #7017](https://github.com/HMCL-dev/HMCL/pull/7017)

公开改动在中国大陆地区拦截游戏版本下载；该 PR 的代码和记录还显示其引入地区判断与限制提示。该项目此前 Issue #5864 已讨论过地区检测准确性，维护者当时明确指出检测可能误判。两条记录分别对应**地区判断的技术取舍**和**下载功能变更**，不应混为一次提案或同一项决定。

### PCL-CE

PCL-CE PR #3673 于 2026-10-20 合并。PR 原始说明称，受近期事件影响，暂时禁止中国大陆地区用户下载、安装和补全 Minecraft 本体及整合包。[PCL-CE PR #3673](https://github.com/PCL-Community/PCL-CE/pull/3673)

PR 文件变更涉及地区评估、下载、安装、修复、加载器及整合包入口；变更说明称，在受限地区仅允许使用已完整存在于本地的游戏文件启动，不自动下载缺失文件。后半部分功能范围可在 PR 的代码差异中核对。该 PR 未在原始说明中列出具体法规或外部事件的名称。

### 原因信息的边界

同日的社区讨论和视频出现了关于投诉人、私服充值、监管要求及网易介入的推测。维护者的公开发布说明只明确写到合规原因，并否认与网易、微软、Mojang 有关。本文查阅的公开记录**不足以确认**具体法律条款、相关机关是否发出指令、具体投诉人或私服是否构成触发原因，也不足以确认其他公司参与了决策。未确认的说法在本文不作为事实陈述。

## 4. PCL 远程公告/配置执行能力争议（2026-10）

### 报告与分析的时间线

- **2026-10-21：** 研究者 MiRin 发布 PCL 2.99.0.0 的 `notice.json` 分析报告。报告称其检查的程序样本与官方仓库所附 2.99.0.0 文件的 SHA-256 相同，并描述客户端从服务器获取公告/配置数据后，会解释其中的动作字段；报告认为其中一条配置路径可以影响启动前执行命令的设置。[研究者报告与 PoC 仓库](https://github.com/MiRinFork/PCLPoC)
- **2026-10-23：** 另一名研究者发布独立的逆向分析，称其使用 dnSpy 检查 PCL 2.99.0.0，并说明公告 ID、公告 JSON 与启动设置之间的调用关系。[独立分析文章](https://www.mrxiaom.top/post/pcl-notice-rce-discovery/)
- **2026-10-24：** PCL GitHub 上出现要求维护者正式回应安全报告和近期下载功能变更的 Discussion #9544。参与者对“后门”这一称呼、报告证明了什么以及何种风险可接受存在分歧。[PCL Discussion #9544](https://github.com/Meloong-Git/PCL/discussions/9544)

### 报告主张与证据边界

报告作者将该设计称为远程代码执行风险/“后门”，并提供其分析过程和 PoC 材料。其核心主张是：远程公告或配置数据可触发客户端的既有设置/更新动作，并在特定条件下到达客户端的命令执行路径。第二篇文章对相关二进制和设置调用链作了独立检查。

“存在一条可到达命令执行的设计路径”与“开发者曾经投放恶意内容”是不同命题。所引报告与讨论证明有研究者提出并展示了前一项主张；本文没有找到能证明 PCL 维护者曾用该路径对普通用户实施恶意执行的公开证据。也没有找到可核实的野外攻击事件、受害用户清单或事件响应报告。本文因此不把“恶意利用已经发生”写作事实。

对“后门”还是“危险的远程管理/公告功能”的称谓，PCL Discussion #9544 中存在公开分歧。安全术语的适用取决于定义和威胁模型；本文记录各方用词，不作裁定。2026-10-24，一篇独立分析文章更新称，PCL 维护者决定在下一版本增加云控配置黑名单，并链接到一篇爱发电说明。[维护者说明链接](https://afdian.com/p/4ab1e3f2cecf11f1836552540025c377) 在本报告核对时该页面无法读取，因此“计划增加黑名单”是经该文章转述的维护者回应，具体黑名单范围、上线版本及实际发布状态尚不能从可访问的一手页面确认。

PCL GitHub 仓库的 README 将其代码描述为包含“大部分源代码”，并说明代码不会实时更新；研究报告另称其重点审查的远程公告实现不完整地出现在公开源码中。读者可分别查看[上游仓库](https://github.com/Meloong-Git/PCL)和[研究报告](https://github.com/MiRinFork/PCLPoC)。源码公开范围是审计可复现性讨论的一部分，但本段不判断任何项目的总体开源程度。
